# Implementation Roadmap

## Phase 1 — Foundation

- Repository architecture
- Laravel backend bootstrap
- React frontend bootstrap
- Environment configuration
- Docker development environment
- Database connection
- Redis and queues
- API versioning
- CI quality gates

## Phase 2 — Identity and tenancy

- Users
- Roles and permissions
- Staff accounts
- Customer accounts
- Authentication and MFA
- Audit logging

## Phase 3 — ISP network

- Routers/NAS
- MikroTik API adapter
- RADIUS adapter
- IP pools
- Service profiles
- PPPoE accounts
- Hotspot accounts
- Sessions and online-user monitoring

## Phase 4 — Commercial operations

- Products/packages
- Subscriptions
- Pricing rules
- Invoices
- Invoice items
- Payments
- Receipts
- Credits and adjustments
- Taxes
- Discounts
- Payment gateway adapters

## Phase 5 — Automation

- Recurring billing
- Payment reconciliation
- Due-date processing
- Grace periods
- Suspension
- Reconnection
- Notifications
- Scheduled reports

## Phase 6 — User interfaces

- Admin dashboard
- Customer portal
- Router management
- Customer/service management
- Billing centre
- Payment centre
- Reports
- Ticketing

## Phase 7 — Production readiness

- Automated tests
- API documentation
- Security hardening
- Backups and restore procedures
- Docker production profile
- Nginx and TLS
- Monitoring and health checks
- GitHub Actions CI/CD
- Deployment documentation

## Delivery rule

Each phase is delivered as working code with migrations, validation, tests and documentation. Placeholder implementations are not considered complete modules.
